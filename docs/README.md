# Документация проекта CIAO

Документация разделена по назначению:

- [`architecture/`](architecture/) — устройство системы, границы слоёв, ключевые модели и принятые архитектурные решения;
- [`guides/`](guides/) — установка, запуск, написание автоматов и практические сценарии использования.

Основные требования к MVP находятся в [`../specs/CIAO_MVP_TECHNICAL_SPEC.md`](../specs/CIAO_MVP_TECHNICAL_SPEC.md). Согласованные решения раздела 11 реализуются в пакете `ciao`, а эти документы описывают фактический публичный API и его применение.

## Правило актуальности

Если меняется публичный API или семантика исполнения, вместе с кодом необходимо обновить соответствующий архитектурный документ, пользовательское руководство и сквозной пример.
