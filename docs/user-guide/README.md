# Руководство пользователя CIAO

Это исходники чернового руководства пользователя. Документ собирается LuaLaTeX,
не требует `--shell-escape` и не запускает генераторы схем во время сборки.

## Сборка

Из корня репозитория:

```powershell
./docs/user-guide/build.ps1
```

Готовый документ появится в `docs/user-guide/build/user-guide.pdf`.

Для сборки нужны `lualatex` и `latexmk` из TeX Live. Примеры кода в каталоге
`code/` являются вручную сопровождаемыми снимками: при изменении публичного API
их нужно обновлять и отдельно проверять Python-компилятором.

## Структура

- `main.tex` — композиция документа;
- `metadata.tex` — сведения об издании;
- `preamble.tex` — единый стиль;
- `chapters/` и `appendices/` — текст руководства;
- `code/` — воспроизводимые учебные листинги;
- `figures/tikz/` — исходники небольших схем;
- `build/` — локальный результат сборки, не попадает в Git.
